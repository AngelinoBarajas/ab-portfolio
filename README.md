# AB Portfolio

Portfolio site for Angelino Barajas: Webflow designer and developer. Space theme, Figma-canvas UI, heavy micro-interaction.

- `prototypes/` — the approved designs (open `prototypes/home.html` in a browser)
- `tokens/`, `cms/` — Webflow variables and CMS schema + content
- `docs/` — build spec, code map, placeholders, progress
- `code/` — custom scripts Webflow loads

Build instructions for Claude Code are in `CLAUDE.md`.
