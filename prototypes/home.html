    /faq

    Pre-flight checks

    Do you only build in Webflow?+

    Webflow is home base, because clients can edit it after launch. The custom pieces (globes, maps, scroll systems) are plain JavaScript hosted on GitHub, so they aren't locked to one platform.

    Can my team edit the site after launch?+

    Yes. Content lives in the CMS and the build follows Client-First naming. Animations read from CMS fields and stable classes, so editing content won't break them. You get a handoff guide and a walkthrough video.

    Will all this motion slow the site down?+

    Heavy pieces load only when they scroll into view and pause when they leave. Every interaction has a reduced-motion fallback, and each page gets a Lighthouse pass before launch.

    How long does a project take?+

    It depends on scope. A marketing site with one custom interactive centerpiece usually runs [X–Y weeks] from brief to launch.
